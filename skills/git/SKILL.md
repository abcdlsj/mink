# Git Skill

Common git operations and best practices.

## Commands

```bash
# Check status
!git status

# Stage changes
!git add <files>

# Commit with message
!git commit -m "message"

# Push to remote
!git push origin <branch>
```

## Best Practices

- Commit early, commit often
- Write clear commit messages
- Use feature branches
- Pull before push
